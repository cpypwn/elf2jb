This runtime is adapted from [NiftyNova/GPUBrewLauncher](https://github.com/niftynova/gpubrewlauncher) at commit `f35ff64ea4b9b42cf2a75095d24662fe250f03e4`, itself based on RavensClawX's HBLauncher. The original contributor credits are retained in [CREDITS](CREDITS).

The PS5 host uses GPUBrewLauncher's Switch GPU stages with the Cellenseres held RPC connection. The app catalog has been reduced to one bundled showcase and rasterized ahead of time so the PS5 does not need Python or Pillow. The launcher opens that app automatically.

The upstream repository does not include a root license file at the snapshot used here.
