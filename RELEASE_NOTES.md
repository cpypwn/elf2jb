# elf2jb v0.1.6

the bundled Cellenseres ns2jb host now passes step 2/4 in PS5 testing. after 4/4 verification, elf2jb holds RPC open and automatically sends a GPU greeting to the Switch 2. the browser opens automatically, and the host can be restarted after a failed attempt.

tested on ps5 pro firmware 13.60, with both consoles connected by ethernet to the same wired network. a complete 4/4 run and the GPU greeting still need Switch testing.
